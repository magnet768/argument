このサイトの使い方

このサイトは、哲学・倫理学における論争を立場の分かれうる最小単位の命題まで細分化し、論理座標を用いて論証全体の構造を整理することで、「立場ごとの通読」と「反対命題との比較」を両立させた論証エクスプローラーです。

1. 論理座標の読み方

論証を構成するすべての命題には、論理座標が付与されています。

+1.21 ⇄ -1.21
  • 符号（+ / -）：対立する2つの立場を表します。同じ番号で符号を反転させた命題どうしが、1対1で直接対立するペアになっています。
  • 整数部（1, 2, ...）：上部タブに対応する「水準」を表します（例：理想論の水準、実践規範の水準など）。
  • 小数第一位（.0, .1, ...）：.0 はその水準の基本命題、.1 以降はその水準の中でのトピック群（価値論、同意、義務論など）を表します。
  • 小数第二位（.00, .10, .11, ...）：0 がそのトピックの基底命題、1 以降がさらに細分化された分岐命題です。

2. 基本的な操作と閲覧モード

論題と水準を切り替える

最上部の「論題」プルダウンからテーマを選び、その下の水準タブで読みたい水準（または「全命題」）を切り替えることができます。

4つの表示モードを使い分ける

+ / - では一方の立場に属する命題だけを通読できます。⇄ 比較では対立する命題を左右に並べて俯瞰でき、☆自説では自分が採用した極性の命題だけを一覧表示できます。

極性（符号）の反転と主張の評価

各カードの「⇄ 反転」ボタンを押すと、対向する立場の同一座標の命題へ即座に移動して強調表示できます。また、一覧カードおよび詳細ページの「+ / = / -」ボタンから、各主張をその論題の + 側・保留（=）・- 側のいずれかで評価してブラウザに記憶させられます（初期状態は=）。ある主張の評価を変更すると、それを前提とする主張が自動的に同じ評価になります。

前提・被参照リンクと検索

±1.10 のようなチップを押すと、水準をまたいで前提命題や参照元の命題へ移動できます。検索欄では座標・キーワード・参考文献から命題を絞り込むことができます。

3. PCとスマートフォンでの見方

  • PCで閲覧する場合：左側に命題一覧、右側に選択中の座標の「1対1比較・参考文献・閲覧者コメント」が表示されます。各命題カードをクリックすると右側のパネルが切り替わります。右側上部の「⤢ 拡大」を押すと、その座標だけの集中画面に切り替えられます。
  • スマートフォンで閲覧する場合：一覧画面で任意の命題カードをタップすると、その座標の専用詳細ページへ移動します。詳細ページ右上の「💬 コメント」からコメント欄へすぐ移動でき、「← 一覧」（または端末の戻る操作）で元のスクロール位置へ戻れます。

4. 参考文献・コメント投稿・URL共有

  • 参考文献の確認：各座標の詳細パネル下部に、その命題に関連する書籍・論文・参照URLが整理されています。この項目は管理者のみ編集・削除できるようになっています。
  • 論題・命題へのコメント投稿：命題一覧ページ最下部から論題全体へ、また各座標の詳細ページから個別の命題（座標全体・+側・-側）へ補足・反論・疑問を投稿できます（最大1000文字、空欄で匿名）。投稿したコメントは、同じ端末・ブラウザから本人のみ編集・削除できます。
  • 管理者へのコメント投稿：各座標の参考文献の修正提案、命題・論証の修正提案、またはサイト全体へのご意見がある場合は、左上メニューの「管理者ページ」下部にある「管理者へのコメント」欄から、該当する論題・座標を指定して投稿できます（こちらも投稿した本人のみ編集・削除が可能です）。
  • 特定座標のURL共有：命題を選択するとブラウザのURL末尾に #論題ID/+1.10 のような座標が自動付与されます。そのURLを共有すると、相手がその命題を直接開いた状態でアクセスできます。

論証のバックアップ / 復元

1. テキストデータでバックアップを作成

論証集としてそのまま読めるテキスト形式（.md）で保存します。同じファイルから論題・水準・命題・参考文献を復元できます。

2. バックアップテキストから復元

保存したファイル（.md / .txt）を読み込むか、テキストを貼り付けてDBへ復元します。同じID・座標は上書きされ、バックアップに含まれない既存データは保持されます。
