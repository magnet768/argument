このサイトの使い方

このサイトは、哲学的・倫理的な論争を立場の分かれうる最小単位まで細分化し、 数値座標を用いて「立場ごとの通読」と「対向論証との即座の比較」を両立させるための論証エクスプローラーです。

1. 座標インデックスの読み方

すべての論証には、極性（符号）と論理座標からなる固有のインデックスが付与されています。

+1.21 ⇄ -1.21
  • 符号（+ / -）：対立する2つの立場を表します。同じ番号で符号を反転させた論証どうしが、1対1で直接対立する論点ペアになっています。
  • 整数部（1, 2, ...）：上部タブに対応する「主張段階」を表します（例：理想論レベル、実践規範レベルなど）。
  • 小数第1位（.1, .2, ...）：その段階の中でのトピック群（価値論、同意、義務論など）を表します。
  • 小数第2位（0, 1, 2...）：0 がそのトピックの基底命題、1 以降がさらに細分化された分岐点です。

2. 基本的な操作と閲覧モード

論題と主張段階を切り替える

最上部の「論題」プルダウンからテーマを選び、その下の段階タブで読みたい階層（または「全論点」）を切り替えます。

3つの表示モードを使い分ける

+ / - まとめでは一方の立場だけを筋道立てて通読できます。⇄ 並置比較に切り替えると、全論点の賛否を左右に並べて俯瞰できます。

符号反転ジャンプと履歴戻り

各カードの「⇄ 反転」ボタンを押すと、対向する立場の同一座標へ即座に移動して強調表示されます。「↩ 元の論証へ戻る」で直前の位置へ戻れます。

前提・被参照リンクと検索

±1.10 のようなチップを押すと、段階をまたいで前提論証や参照元の論証へ移動できます。検索欄では座標番号・本文・参考文献から絞り込めます。

3. PCとスマートフォンでの見方

  • PCで閲覧する場合：左側に論証一覧、右側に選択中座標の「1対1対照比較・参考文献・閲覧者コメント」が表示されます。各論証カードをクリックすると右側のパネルが切り替わります。右側上部の「⤢ 拡大」を押すと、その座標だけの集中画面に切り替えられます。
  • スマートフォンで閲覧する場合：一覧画面で任意の論証カードをタップすると、その座標の専用詳細ページへ移動します。詳細ページ右上の「💬 コメント」からコメント欄へすぐ移動でき、「← 一覧」（または端末の戻る操作）で元のスクロール位置へ戻れます。

4. 参考文献の確認・コメント投稿・URL共有

  • 参考文献：各座標の詳細パネル下部に、関連する書籍・論文・参照URLが整理されています。
  • コメントの投稿：どの座標に対しても、座標全体・+側・-側のいずれかを指定して補足・反論・疑問を投稿できます（最大1000文字、空欄で匿名）。
  • 特定座標のURL共有：論証を選択するとブラウザのURL末尾に #論題ID/+1.10 のような座標が自動付与されます。そのURLを共有すると、相手がその論証を直接開いた状態でアクセスできます。
